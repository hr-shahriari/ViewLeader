About this example

The question: how much editing do you get from editing: { gestures: true }? This page contains no pointer handler at all.

  • Drag a label to place it by hand. Drag an arrowhead grip onto a different part of the building and the anchor re-picks through this page’s raycaster. Drag a route grip to bend the leader. Grips exist only once the annotation is selected, so click it first.
  • Click a label to select it; shift-, ⌘- or Ctrl-click toggles another in or out. Shift-drag empty space to rubber-band a marquee, and alt-drag to subtract from the selection.
  • The camera keeps its usual buttons — left orbits, right pans, middle dollies. Passing adapters.controls is what buys that: with an interaction adapter present marquee already defaults to 'none', so core never takes the lease on a press that misses an annotation and OrbitControls’ own pointerdown runs to completion. marquee: 'modifier' then asks the rubber band back, on a shift- or alt-drag only. A left-drag that starts on an annotation edits instead: core takes an interaction lease and the adapter switches OrbitControls off while it holds one. Scroll to zoom works over a label too, because the page passes forwardWheelTo — without it the label’s hit pad swallows the wheel.
  • Watch the pointer: core writes the cursor on hover, so anything draggable reads move, and a midpoint grip that will insert a bend reads copy.
  • Escape cancels a drag in flight, and each gesture is exactly one undo step.
  • Buttons: Align left · Distribute vertically · Snap to grid (6 mm — it draws the grid it snaps to, and the same hook snaps the live drag preview and automatic placement alike; a dropped label lands on a line and then travels with its anchor as you orbit) · Reset all edits · Undo.
  • Orbit until an anchor swings behind the building — that leg draws dashed and dimmed (ISO 128: dashed means hidden) while the label stays at full strength.

API: new ViewLeader({ boundary, editing: { gestures: true, marquee }, strategies: { snap }, forwardWheelTo }) · adapters.pick · adapters.controls · annotations.align('left') · annotations.distribute('y') · resetPlacement/resetRouting · editing.subscribe() and editing.getSnapshot() · history.transaction/undo
