About this example

The question: what do the built-in drafting styles look like, and what is a style as opposed to a theme?

  • Eleven styles ring the building. Each annotation names a styleId and nothing else — arrowhead, enclosure, landing and text alignment all come from the definition, in drafting units.
  • Theme (paper / dark) — serialize, rebuild the instance on the other palette, reopen the same bytes. Same ids, no document edit: a theme is a rendering choice, like a camera.
  • Routing — re-routes all eleven, because routing is per annotation, not per style.
  • Toggle long landings — a typed partial deep-merged over each style, reaching only the landing’s length.
  • Measure a label — reads the standard label’s pixel box back out of the frame that was actually drawn.

API: annotations.create({ styleId }) · annotations.update({ routing, styleOverride }) · theme: CAD_PAPER | CAD_DARK · documents.serialize() · geometry.of(id) · BUILT_IN_DEFINITIONS · mm()
