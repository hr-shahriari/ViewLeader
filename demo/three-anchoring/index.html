About this example

The question: how does a note stay on its element when the host resolves ids asynchronously?

Try: reload the page and watch the tag. It draws first at the fallbackPoint stored in the document — down at ground level, deliberately wrong — then snaps to the real front door about 600 ms later, when this page’s resolver answers. Neither step edits the document. Orbit and it re-sides around the model.

Orbit until an anchor swings behind the building — that leg draws dashed and dimmed (ISO 128: dashed means hidden) while the label stays at full strength.

API: annotations.create({ anchor: { kind: 'element', modelId, elementId, fallbackPoint } }) · createStableElementResolver() · createThreeAdapter({ resolveElement })
