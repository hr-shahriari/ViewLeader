About this example

The question: what happens to plugin content on a machine where the plugin is not installed?

Try: Remove plugin rebuilds the runtime from the same serialized bytes with the Markdown plugin left out — the record survives intact and draws as a safe placeholder. Restore plugin rebuilds with it, and those same bytes render as Markdown again. Nothing is rewritten in between; the document is serialized once, before either press.

Orbit until an anchor swings behind the building — that leg draws dashed and dimmed (ISO 128: dashed means hidden) while the label stays at full strength.

API: documents.serialize() · new ViewLeader({ initialDocument, plugins }) · leader.dispose() · the plugin:viewleader.markdown content kind
