About this example

The question: what does one runtime look like with every capability wired at once — and does it clean up after itself?

  • Compose review — a Markdown note, an ink stroke on the front wall, a saved view and a selection, in one pass.
  • Crowd (30 notes) — a deliberately dense drawing. Orbit it and watch the placer keep the labels off each other.
  • Standards: N — a live drafting-standards lint, re-run every frame, so the count changes as you orbit. Click it to select the annotations it is complaining about.
  • Dispose — tears the runtime down. The canvas keeps painting and nothing ViewLeader owned is left in the boundary.
  • Export sheet — the composed drawing as a standalone SVG with a title block, straight from leader.overlayElement. Grips and hit targets are marked data-non-printing where core creates them, so the file holds the drawing and nothing else.
  • Orbit until an anchor swings behind the building — that leg draws dashed and dimmed (ISO 128: dashed means hidden) while the label stays at full strength.
  • Occlusion — what a buried leg does, set on every annotation at once in a single undo step. keep, the default, dashes and dims it. fade also drops a note whose every leg is buried to a quarter opacity. hide does not draw a buried leg at all — no stroke, no arrowhead, no click target — so crowd the drawing and then pick it: the leaders pointing into the far side of the building stop competing for attention and the review becomes readable.
