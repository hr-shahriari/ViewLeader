About this example

The question: how do you draw a region on the model, and point one label at several things at once?

Try: the revision cloud on the front wall and the three-leg “Openings” callout are both committed at load, through the same public markup API a pointer tool would drive — the geometry is handed in, so no gesture is needed. Orbit: the cloud stays on the wall’s plane and the three legs re-route to keep one label readable. Undo last leg unwinds one markup edit per press.

Orbit until an anchor swings behind the building — that leg draws dashed and dimmed (ISO 128: dashed means hidden) while the label stays at full strength.

API: authoring.markup.start({ kind, plane, draft }) · setRegionGeometry(geometry, 'keyboard') · markup.complete() · markup.addAnchor(id, leg) · history.undo()
