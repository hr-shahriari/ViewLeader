About this example

The question: who owns the ViewLeader instance in a React app, and what happens when the boundary unmounts?

Try: Replace boundary bumps the key on the mounted component. React unmounts the old boundary — disposing its ViewLeader with it — and mounts a fresh element, which the hook constructs on and the effect seeds again; the note’s title counts up (React #2, #3…). Nothing is constructed at module load or on the server.

Orbit until an anchor swings behind the building — that leg draws dashed and dimmed (ISO 128: dashed means hidden) while the label stays at full strength.

API: useViewLeader({ adapters }) → { boundaryRef, viewLeader } · annotations.create() · leader.update()
