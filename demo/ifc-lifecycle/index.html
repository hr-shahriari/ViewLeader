About this example

The question: what happens to an annotation when the model under it is unloaded and loaded again?

Try: Unload model — the building goes, the resolver reports no sources, and the note falls back to the point the document stores. Reload model — the id re-resolves and the note snaps back onto the corner column. The canonical document is never touched either way.

Orbit until an anchor swings behind the building — that leg draws dashed and dimmed (ISO 128: dashed means hidden) while the label stays at full strength.

API: createThreeElementInvalidationChannel() · invalidations.invalidate({ modelId }) · createStableElementResolver() · annotations.create()
